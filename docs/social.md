# 主动陪伴与 B 站主人私信

这些功能默认关闭，配置保存后生效。账号仍需在你的本机登录，DSH 必须保持运行。下面的“意愿”来自模型的有限选择和带权重的动机，不代表系统具有人的意识。

## QQ 主动私聊

在 **QQ 连接 → 想你的时候，主动聊一会儿** 开启“允许主动私聊主人 QQ”。只向上方 `主人 QQ 号` 发送文字，不主动联系其他私聊白名单或群聊。SnowLuma 应保持在线，主人号与登录号需不同。

| 活跃程度 | 行为 |
|---|---|
| 沉默 | 不主动考虑，也不主动发送 |
| 安静 | 考虑间隔上界变为配置上界的两倍 |
| 适中 | 在配置的最短间隔到上界内安排考虑 |
| 活跃 | 考虑间隔上界缩短至一半，但不突破最短间隔 |

默认最短 60 分钟、上界 240 分钟；每天最多思考 8 次、尝试发送 4 次。每分钟检查一次是否到该考虑的时间，单纯计时不调用模型。档位不保证每天发几条消息，模型可以一直选择安静。

陪伴、关心、分享、玩耍、只是想聊天分别设权重，按比例抽取本轮动机；0 表示不选择，各项不必相加为 100。随后一次思考决定是否发送，不能为了动机编造你的健康、近况或它的经历。默认只携带 1200 字符内的当天笔记与近期对话，输出预算 480 Token，不搜索所有历史。

作息统一使用“角色与回复 → 生物钟”，推荐 23:00 睡觉、08:00 起床；生物钟关闭时不另设平台免打扰窗口。收到主人新消息后的十分钟内不主动插话。“主人未回复时暂停继续主动联系”默认开启，持续跨重启生效；主人发来新消息并经过缓冲后才恢复。

“现在考虑要不要找主人”立即提交后台思考，仍遵守沉默、免打扰、间隔、未回复暂停和每日额度。停止当前思考不关闭以后考虑；长期停用需关闭开关或选择沉默并保存。每日发送上限统计尝试数，发送结果未知仍占额度，不自动重发。每次思考也会产生少量 Token，在 **Token 用量 → QQ 主动联系** 单列。

## B 站主人 UID 与私信

在 **B 站账号 → 在 B 站，也认得主人** 填写主人的数字 UID，每行一个，按需填写。UID 来自主人的个人主页 `space.bilibili.com/数字`，不要填机器人登录号。

这些 UID 都被视为主人：能读取同一份主人记忆，也能通过明确要求使用已开启的 B 站操作工具。因此白名单只添加自己的账号。其他 UID 的私信不读取、不生成回复。

开启“回复主人 B 站私信”并保存，默认每 60 秒检查一次。**首次启用只建立该登录账号与主人 UID 的消息边界，请等第一次检查完成后再发新的文字私信。** 历史未读消息不补回。切换登录账号会重新建立边界。

只处理新来的普通文字，跳过自己发送、撤回、系统和不支持的消息类型。默认每天最多尝试回复 20 条，至少间隔 10 秒；本轮未回复的后续消息留待下次。QQ 与 B 站共享有预算的当天笔记与主人近期原话，保存说话人和问答关联；历史仍需明确追问才检索。

每条消息在生成前记录领取回执及 64 位序号，重启不重复生成或发送。失败和未知状态不自动补发；需要你在平台核实。网络轮询不产生模型 Token，实际回复记为 **B 站私信**；回复中使用 B 站工具的整轮仍归 **B 站任务**。

平台的私信接收范围、关注关系、验证码与账号限制仍可能影响接口。遇到平台验证请使用官方客户端；接口接入和自动测试通过不等于每个真实账号都能直接发送。

## 在视频评论里 @ 主人推荐

同时满足：

1. 主人 UID 白名单已填写。
2. 开启“允许发表评论”。
3. 自主生活已开启，并开启“发现有趣视频时在评论 @ 主人推荐”。
4. 开启视频内容识别和自主识别，本轮实际识别过该视频内容。

浏览后模型可决定是否推荐，也可以不推荐。插件查询白名单账号的真实昵称，在评论中提交 `at_name_to_mid` 对应关系，避免只是显示一段 `@文字`。昵称无法核验时停止，不假装成功；不能 @ 当前登录账号自己。

推荐与普通自主评论每轮合计最多一条，共用账号的每日评论额度和最小间隔。评论是公开内容，不包含主人私聊原文；成功以平台评论 ID 为准，是否收到通知由平台决定。

接口依据：[私信消息](https://github.com/bilibili-plugins/bilibili-api-collect/blob/master/docs/message/private_msg.md)、[消息内容](https://github.com/bilibili-plugins/bilibili-api-collect/blob/master/docs/message/private_msg_content.md)、[@ 评论请求实现参考](https://github.com/jackwener/opencli/blob/main/clis/bilibili/comment.js)。本版本没有登录真实账号发送消息或公开评论。

## 没看到主动行动，先看状态

QQ 区域直接列出未开启、沉默档、回复关闭、桥接断开、睡眠、额度用完、最短间隔、主人刚说话十分钟内及等待回复等原因；没有阻碍时显示下次考虑时间。首次开启默认先安排 60–240 分钟内的一次考虑，不会立即保证发消息。“现在考虑”可以提前检查，但不跳过作息、额度和等待回复约束，模型也可选择安静。

B 站区域列出工具 / 登录 / 标签 / 作息 / 次数状态，以及实际允许的评论、点赞、动态和 @ 推荐权限。只有“允许发表评论”和“浏览时可自主评论”同时开启才能自主留言，单独开评论工具只允许主人明确要求。状态为“未开启”时不会暗中替你打开公开发布。
