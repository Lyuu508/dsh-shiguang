# 双击头像：拍一拍、搓一搓、揉一揉

在 **QQ 连接 → 双击头像，也接住你的互动** 开启，仍需 QQ 回复总开关、QQ 在线及 SnowLuma 连接。头像互动默认开启、100% 回应，同一人同一会话冷却 30 秒。测试可暂时用冷却 0；普通文字的主人 95% / 其他人 85% 不再次叠加。

QQ 里把动作改为拍一拍、搓一搓或揉一揉都可使用：插件按 OneBot `notice / notify / poke` 的目标账号识别，不按文字关键词匹配。SnowLuma 私聊的实际触发人来自 `sender_id`；群通知来自 `user_id`。只回应发给伙伴自身的互动，不回应自己戳自己、其他人互戳或聊天里伪造的“拍一拍”文字。

- 私聊仅主人和允许私聊账号；群内还需白名单群与“允许在白名单群回应头像互动”。群里无需再 @，回复留在原群，不带出主人私聊记忆。
- “未上报动作时的称呼”仅在桥接没有提供动作名时使用，不会修改 QQ 官方动作配置。“头像互动回应习惯”只控制语气。
- 仍使用原有等待 / 合并和气泡节奏；收到的事件及真实回复保存到同轮记忆，标为头像互动，不冒充对方亲口说过的话。
- 睡眠期间默认不被头像互动叫醒。可在 **角色与回复 → 生物钟 → 睡眠期间允许被头像互动叫醒** 开启，沿用该处叫醒概率、清醒时长与最小间隔；没有额外 QQ 作息。
- 事件未选中只归档，不调用回复模型；选中后一次正常聊天调用。纯互动不取得 B站操作、梗教学或事实笔记工具。

若没有反应，先看本区最近状态、总开关和冷却，再确认 SnowLuma 是否实际收到该通知。没有原生通知时插件不会通过轮询头像猜测双击。字段依据 [SnowLuma 通知转换源码](https://github.com/SnowLuma/SnowLuma/blob/f2ea3354f8bbe8672cbb4ae6a2b4e1fbeff44faf/packages/onebot/src/event-converter/to-notice.ts)，已用真实本机 WebSocket 与 DSH AgentLoop 验证；Windows 账号事件仍需本机联调。

绑定的主人触发互动时，会收到“对主人的称呼”表达习惯，默认自然叫一次“主人”；按真实 QQ 号识别，不把其他群友叫成主人。
