# 更新检查与网络超时

在 **设置 → 拾光 → 版本更新** 点“检查更新”，请求立即返回，后台继续检查，页面每两秒刷新状态。离开设置页不取消检查或下载；可点击“取消当前网络请求”终止检查或下载。进入 DSH 安装阶段后不取消安装事务。

GitHub API 不可用或限额时，自动读取官方仓库的 `downloads/latest.json`。默认每个元数据请求等待 15 秒、失败重试 2 次；安装包下载每次最多等 300 秒。可在“连接与下载设置”调整并保存，再重试。后台检查避免页面 RPC 的固定等待时间提前打断操作，网络本身仍可能失败。

安装包可配置自己信任的 HTTPS 加速前缀，留空直连。只加速包文件，版本信息和 SHA256 记录仍从官方仓库读取。校验失败不会交给 DSH 安装；不内置未经核验的公共镜像。检查、下载、安装分别显示状态，下载显示已收大小。源码 ZIP 不参与自动安装。

**0.1.6 或更早版本的更新页仍使用旧逻辑**。如果旧按钮一直超时，将下面这句话发给 DSH，先安装修复版本：

> 帮我从 Lyuu508/dsh-shiguang 的 v0.1.8 Release 链接下载预构建 TGZ，核对 SHA256，安装到当前 profile，保留已有配置和记忆，完成后提醒我重启 DSH 并刷新页面。

也可以在 [版本页](https://github.com/Lyuu508/dsh-shiguang/releases/tag/v0.1.8) 下载 `dsh-shiguang-0.1.8.tgz` 和对应 `SHA256SUMS-0.1.8.txt`，核对后交给 DSH 插件管理安装。账号、配置和记忆位于独立数据目录，不在安装包内。

安装成功后按提示重启 DSH 并刷新页面。若安装结果不明，先看 DSH 插件管理中的版本和诊断，避免反复安装。安装状态会保存在本机；进程中断后再次打开会提示核实。
