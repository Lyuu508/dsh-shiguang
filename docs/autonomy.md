# B 站自主生活

在设置 → 拾光 → B 站账号 → 自主生活中配置。默认关闭；需要先在 B 站账号页面扫码登录并启用 B 站。

## 标签范围

填写实际 B 站标签，每行一个。搜索从白名单关键词开始，候选视频必须再通过真实标签接口核对。黑名单优先；不匹配白名单、匹配任一黑名单或无法确认标签时，不把该视频交给模型，也不自动评论。

主人手动指定的视频默认不强制命中白名单，黑名单仍优先。需要严格筛选时开启“手动读取也要求白名单”，拦截消息会列出实际标签和匹配原因。自动浏览必须有非空白名单。标签采用 NFKC、去首尾 #、不区分大小写的完整名称匹配，不按标题猜测标签。标签缓存最长五分钟；配置变更后重建服务。

搜索使用 B 站 Web 的 WBI 签名接口与已登录的会话，自动补齐普通浏览所需的 buvid3。遇到登录过期、验证码或网络异常会停止本次任务，不绕过验证。

## 先选择醒来方式

固定时刻：按下方每天的 HH:mm 时间表执行。自由醒来：不使用固定钟点，首次在最短到最长间隔内安排下一次考虑，之后由每轮的浏览意愿决定下次间隔。默认范围 45–240 分钟、休息窗口 23:00–08:00，均可修改。

自由模式的下次时间保存在数据库中，重启复用，不无限补跑错过的次数；每 30 秒检查是否到期，检查时钟本身不调用模型。休息窗口内不运行自由任务，跨日额度与固定模式相同。没有新视频或模型失败时，使用范围内的随机间隔兜底，避免连续空转。手动醒来立即执行，不等下一次时刻。

## 醒来与发布

- 默认配置三个时间：09:00、15:00、21:00，可按需增加时间，不再限制为 8 个。
- 按插件配置的时区计算，DSH 运行时每 30 秒检查一次；最多接续 15 分钟内刚错过的时段，不追赶连续补跑。
- 每天同一个时间只执行一次，账本持久化；重启、夏令时重复小时不重复执行。手动测试也计入每日次数上限。
- 每次核验有限候选，默认最多浏览两个新视频介绍；已记录的视频不重复浏览。
- 默认浏览标题、简介、作者和标签；另行开启视频识别及“自主浏览时也识别视频内容”后，可增加抽样画面与可用字幕摘要，不转写原始音频。视频识别独立限额，见 [视频内容指南](bili-video.md)。没有新内容且没有可用灵感时，不调用模型。
- 默认开启“醒来后自己选择想刷的视频”：先用一次有限文字思考，选择看哪些候选以及浅看 / 深看，可以跳过全部；不能选择提供列表外的视频。
- 允许自主深看还需视频识别和自主识别权限。浅看每个视频一次视觉调用；深看按段计费、覆盖整个分 P 的时间范围，超预算不假装看完。
- 有见闻时，再用一次有限文字思考，决定是否评论、@ 主人推荐、发动态或什么都不发。关闭意愿选择可保留直接浏览候选的旧行为，但自由间隔使用兜底安排。
- 推荐需主人 UID 白名单、推荐开关、评论权限和本轮实际识别到的视频内容，与普通评论每轮合计最多一条。[主人 UID 与推荐说明](social.md)

“允许发表评论”决定账号是否能评论；“浏览时可自主评论”决定定时任务是否能自行评论。每次最多一条，遵守 B 站账号页的总次数和间隔。动态同样需要同时开启账号发布权限和自主决定开关，默认每天最多两条，至少相隔一小时。

收到平台评论 ID / 动态 ID 才记录成功。发送结果未知也占用额度，并阻止同一操作自动重发；任务日志不会把“已尝试”写成“已发布”。一轮中多个外部操作不是事务，可能评论成功而动态失败，应该以各自回执和平台状态为准。

需要立即中断时，点“停止当前自主任务”。这会取消本轮下载或思考；已发出的平台请求仍需核实。后续时段不受影响，要长期关闭请关闭自主生活开关并保存。保存设置会等待队列中的工作结束。

## QQ 记忆与公开动态

主人 QQ 私聊、主人重要笔记、B 站见闻和发布回执共用 `owner` 记忆；各个群聊继续隔离。每次醒来的简短决定也作为私人 DSH 笔记进入同一份记忆，方便之后询问，但不作为自动公开发布的材料。

导入文件的记录不作为自动公开发布的灵感来源；它们仍可在私聊中正常检索。

默认不给自主发布提供 QQ 私有笔记。打开“允许今天 QQ 重要笔记作为动态灵感”后，只取主人当天限量的重要笔记和见闻，不取原始私聊，不取其他群的记录。笔记只是资料，模型被要求匿名化、不复述隐私；程序也会阻止含明显号码、邮件、凭据等的草稿，但这不是完善的隐私识别器。请只对你愿意公开改写的内容开启这个选项。

自主思考的 usage 单独记为“B 站自主生活”。搜索、筛选标签、查本地记忆不调用模型；实际用量及缺失情况见 Token 用量。

插件不控制 Windows 电源，不会唤醒关机电脑。Web 接口、账号验证和发布资格以 B 站实际返回为准；当前测试不登录真实账号。

接口参考：[WBI 搜索](https://github.com/bilibili-plugins/bilibili-api-collect/blob/master/docs/search/search_request.md)、[视频标签](https://github.com/bilibili-plugins/bilibili-api-collect/blob/master/docs/video/tags.md)、[发布动态](https://github.com/bilibili-plugins/bilibili-api-collect/blob/master/docs/dynamic/publish.md)。

生物钟开启后，睡眠时不开始新的自主任务；发布前再次检查状态，已经到睡眠时间则不再互动。另可开启账号点赞权限和“浏览时可自主点赞”，每轮按意愿至多点赞一条，继续遵守独立点赞额度与间隔。见 [生物钟说明](clock-emoji.md)。

## 主人的兴趣与标签权重

在 B 站页单独扫码登录主人账号，读取最近观看视频的真实标签；选择后加入伙伴浏览白名单并保存。读取仅使用平台接口，不调用模型，不把整份主人历史写进共享记忆。主人凭据单独存放，写操作在代码中拒绝；停用主人凭据不会退出伙伴账号。

白名单标签可拖动排序，也可按上移 / 下移按钮；权重为 1–10，推荐先设 5。主题选择按权重抽样，并非必选最高项；实际视频仍须命中白名单且避开黑名单。排序改变列表展示顺序，概率由权重决定。

起床睡觉统一在角色页生物钟设置；固定浏览时刻或自由考虑间隔仅决定清醒期间何时想去浏览，不另设 B 站作息。
