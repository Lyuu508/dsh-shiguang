# B 站自主生活

在设置 → 拾光 → B 站账号 → 自主生活中配置。默认关闭；需要先在 B 站账号页面扫码登录并启用 B 站。

## 标签范围

填写实际 B 站标签，每行一个。搜索从白名单关键词开始，候选视频必须再通过真实标签接口核对。黑名单优先；不匹配白名单、匹配任一黑名单或无法确认标签时，不把该视频交给模型，也不自动评论。

有白名单时，主人直接要求读取或评论的视频也需通过相同筛选；仅配置黑名单时，点名视频仍会排除黑名单。自动浏览必须有非空白名单。标签采用 NFKC、去首尾 #、不区分大小写的完整名称匹配，不按标题猜测标签。标签缓存最长五分钟；配置变更后重建服务。

搜索使用 B 站 Web 的 WBI 签名接口与已登录的会话，自动补齐普通浏览所需的 buvid3。遇到登录过期、验证码或网络异常会停止本次任务，不绕过验证。

## 醒来与发布

- 默认配置三个时间：09:00、15:00、21:00，可改为每天 1–8 个时间。
- 按插件配置的时区计算，DSH 运行时每 30 秒检查一次；最多接续 15 分钟内刚错过的时段，不追赶连续补跑。
- 每天同一个时间只执行一次，账本持久化；重启、夏令时重复小时不重复执行。手动测试也计入每日次数上限。
- 每次核验有限候选，默认最多浏览两个新视频介绍；已记录的视频不重复浏览。
- 浏览内容是标题、简介、作者和标签，不是播放画面或声音。没有新内容且没有可用灵感时，不调用模型。
- 有见闻时，使用角色与回复中的模型进行一次限量思考，决定是否评论、发动态或什么都不发。

“允许发表评论”决定账号是否能评论；“浏览时可自主评论”决定定时任务是否能自行评论。每次最多一条，遵守 B 站账号页的总次数和间隔。动态同样需要同时开启账号发布权限和自主决定开关，默认每天最多两条，至少相隔一小时。

收到平台评论 ID / 动态 ID 才记录成功。发送结果未知也占用额度，并阻止同一操作自动重发；任务日志不会把“已尝试”写成“已发布”。一轮中多个外部操作不是事务，可能评论成功而动态失败，应该以各自回执和平台状态为准。

需要立即中断时，点“停止当前自主任务”。这会取消本轮下载或思考；已发出的平台请求仍需核实。后续时段不受影响，要长期关闭请关闭定时开关并保存。保存设置会等待队列中的工作结束。

## QQ 记忆与公开动态

主人 QQ 私聊、主人重要笔记、B 站见闻和发布回执共用 `owner` 记忆；各个群聊继续隔离。每次醒来的简短决定也作为私人 DSH 笔记进入同一份记忆，方便之后询问，但不作为自动公开发布的材料。

导入文件的记录不作为自动公开发布的灵感来源；它们仍可在私聊中正常检索。

默认不给自主发布提供 QQ 私有笔记。打开“允许今天 QQ 重要笔记作为动态灵感”后，只取主人当天限量的重要笔记和见闻，不取原始私聊，不取其他群的记录。笔记只是资料，模型被要求匿名化、不复述隐私；程序也会阻止含明显号码、邮件、凭据等的草稿，但这不是完善的隐私识别器。请只对你愿意公开改写的内容开启这个选项。

自主思考的 usage 单独记为“B 站自主生活”。搜索、筛选标签、查本地记忆不调用模型；实际用量及缺失情况见 Token 用量。

插件不控制 Windows 电源，不会唤醒关机电脑。Web 接口、账号验证和发布资格以 B 站实际返回为准；当前测试不登录真实账号。
