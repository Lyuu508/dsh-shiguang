# 下载拾光 Shiguang v0.1.2

适配 DeepSeek Harness 0.2.2-rc.1，需要 Node.js 24.9 或更新。新增版本检查、下载安装与每日 Token 用量统计。

- **首次安装推荐：** `dsh-shiguang-0.1.2-source.zip`，含源码、已构建客户端与 Host 文件、中文说明和 Windows 安装脚本。
- **预构建 DSH 包：** `dsh-shiguang-0.1.2.tgz`，可通过 DSH 插件安装命令安装或升级。
- **校验：** `SHA256SUMS-0.1.2.txt`。

点击对应文件，再点 GitHub 的 **Download raw file / 下载原始文件**。

首次安装或升级后重启 DSH 并刷新页面，进入 **设置 → 拾光**。QQ 与 B 站账号仍需在你自己的本机登录。

0.1.1 及更早版本请先手动安装本包，重启后就有更新按钮。旧版文件保留供查阅。真实 Windows 与 QQ / B 站账号仍需本机联调；测试边界见仓库 `VALIDATION.md`。
