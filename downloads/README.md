# 下载拾光 Shiguang v0.2.1

适配 DSH 0.2.2-rc.1、Node.js 24.9+。本版增加概率与等待合并回复、分段气泡、自然闲聊、外部 JSONL 记忆卡及完整用量对账，修复禁用按钮的转圈光标。

- [预构建 TGZ](dsh-shiguang-0.2.1.tgz)：交给 DSH 插件管理安装。
- [源码与预构建 ZIP](dsh-shiguang-0.2.1.zip)：源码、中文说明与脚本。
- [SHA256SUMS-0.2.1.txt](SHA256SUMS-0.2.1.txt)：安装前核对摘要。

点 **Download raw file / 下载原始文件**，或从 [版本页](https://github.com/Lyuu508/dsh-shiguang/releases/tag/v0.2.1) 下载。安装后重启 DSH 并刷新页面 → 设置 → 拾光。

QQ 页“听完这一轮，再慢慢回”：推荐 85%、2–6 秒等待、2 秒安静窗口，最多 3 个气泡、段间 1–3 秒；测试可临时设 100%。未选中也保存原话，概率和等待不调用模型。新的输入默认合并当前尚未生成的一轮，已经生成中的新消息留待下一轮。

记忆页直接选 JSONL / NDJSON 记忆卡，预览后导入；保留时间、来源、关联回复与权限范围，默认进历史，文件只当资料。原有配置与记忆保留，v11 升级前备份。

Token 页区分当前角色与整个本机 DSH，保存完整 totalTokens，缺失 / 旧数据明确标注。可从尚有原始回执的旧日志补齐，并手动记录服务商实际账单，不把插件数字冒充全账户扣款。

SnowLuma 仍由你官方下载并解压。没有使用真实平台账号和收费模型进行验证，Windows 与实际账号仍需本机实测，见 [验证记录](../VALIDATION.md)。
