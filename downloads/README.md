# 下载拾光 Shiguang v0.2.0

适配 DSH 0.2.2-rc.1、Node.js 24.9+。本版增加 QQ 关键词唤醒、完整问答记忆和主人跨会话权限，修复回复关闭时的连接检测、视频工具安装误报及自主浏览模型路由。

- [预构建 TGZ](dsh-shiguang-0.2.0.tgz)：交给 DSH 插件管理安装。
- [源码与预构建 ZIP](dsh-shiguang-0.2.0.zip)：含源码、中文说明与脚本。
- [SHA256SUMS-0.2.0.txt](SHA256SUMS-0.2.0.txt)：安装前核对摘要。

点击文件后选 **Download raw file / 下载原始文件**，或从 [版本页](https://github.com/Lyuu508/dsh-shiguang/releases/tag/v0.2.0) 进入。

更新后重启 DSH 并刷新页面 → 设置 → 拾光。先保持 QQ 回复关闭也能检测连接和保存白名单消息。群聊称呼在 QQ 连接中开启，推荐先用 35% 概率、60 秒冷却；睡眠叫醒使用角色页的统一作息。

记忆默认“问答合并”，显示说话人、原话和各自时间；“仅主人可查询跨会话聊天记忆”默认开启。已有配置、角色与记忆保留，升级 v10 前自动备份旧库，旧记录缺失的姓名或原话不会伪造。

主动 QQ / B 站功能仍按开关、作息和权限运行，面板显示未行动原因与下次检查时间。自主评论需同时开启评论权限与自主评论开关。

SnowLuma 仍由你从官方下载并解压；视频工具优先定位，缺失时校验下载。Windows 与真实账号的验证范围见 [验证记录](../VALIDATION.md)。
